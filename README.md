# Carfleet — interaktivní školení

Prezentační web pro školení zaměstnanců o používání služebních vozidel.

## Ovládání

- šipka vpravo / mezerník: další část
- šipka vlevo: zpět
- T: poznámky školitele
- checkpointy a kvíz lze ovládat i myší

Web je záměrně řešený jako jediný statický soubor bez externích závislostí, aby fungoval spolehlivě při sdílení přes Teams i na GitHub Pages.
